# Space Shooter

A fast, arcade-style space shooter game built by **AAH Enterprises**. It runs directly in the browser on phones, tablets and desktops. No install, no server and no libraries.

## Features

**Menus**
- Main menu with Start game, Select level, Select aeroplane, Settings and Exit
- Level select from 1 to 6
- Four ships to choose from, each with its own shape and colours
- Settings for sound, on-screen buttons, difficulty, screen shake and fullscreen
- In-game menu (three-line button) with Resume, Settings and Quit

**Gameplay**
- Your ship fires automatically, so you only focus on moving and dodging
- Three enemy types: normal, fast and tank (needs three hits)
- Level increases as your score grows, and the game gets harder
- Pick-ups: double shot, shield and extra life
- **POWER** button fills as you destroy enemies. When full, it wipes the whole screen
- **TURBO** button gives 4 seconds of extra speed and rapid fire, with a cooldown
- Three difficulty levels: Easy, Normal and Hard
- Best score is saved in the browser

**Controls**
- Touch or mouse: drag to move, or use the on-screen left and right buttons
- Keyboard: arrow keys or A and D to move, Space or E for Power, Shift or W for Turbo, P or Esc for the game menu

**Design**
- Animated loading logo
- Space-purple, neon pink and gold design
- Particle explosions, parallax stars and sound effects generated in code
- Responsive layout and fullscreen mode

## Built with

- HTML5 Canvas for the game graphics
- CSS3 (gradients, grid, animations)
- JavaScript (game loop, collision detection, state management)
- Web Audio API for sound effects
- localStorage for saving best score and settings
- Pointer Events and Fullscreen API

## How to run

1. Download or clone this repository.
2. Open `index.html` in any modern browser.
3. Press **Start game**.

No installation is needed.

## What this project shows

- A real-time game loop with `requestAnimationFrame`
- Collision detection and a simple state machine (menu, playing, paused, game over)
- Responsive canvas scaling and touch support
- Menu design and saved user settings
